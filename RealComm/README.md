# RealComm project page

Academic project page at https://wwwwwli.github.io/RealComm/.

This directory is self-contained HTML/CSS/JavaScript. The homepage Jekyll build copies its HTML, figure, PDF, and audio assets as static files. No extra workflow or root-level Pages setting is required.

The seven figures and downloadable manuscript are synchronized with the RealComm research bundle. The 16 source examples cover English and Mandarin, bona fide speech and seven TTS systems, and eight directed device routes. Each example provides a digital reference and three same-source call configurations. Four examples also provide matched denoising off/on comparisons (76 WAV files in total). All WAV bytes match the frozen manifest; selection uses no detector scores. Authors and publication details are intentionally omitted until confirmed.

To preview locally, serve this directory using any static HTTP server.
