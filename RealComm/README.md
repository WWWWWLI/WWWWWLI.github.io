# RealComm project page

Academic project page prepared for https://wwwwwli.github.io/RealComm/.

This directory is self-contained HTML/CSS/JavaScript. The homepage Jekyll build copies its HTML, figure, PDF, and audio assets as static files. No extra workflow or root-level Pages setting is required.

The seven figures and downloadable manuscript are synchronized with the RealComm research bundle. Paired audio examples use the same iPhone-to-Samsung route with denoising off; samples were selected without detector scores. Authors and publication details are intentionally omitted until confirmed.

To preview locally, serve this directory using any static HTTP server.
